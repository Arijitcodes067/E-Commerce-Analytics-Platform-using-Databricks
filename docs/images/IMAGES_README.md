# Dashboard Screenshots

Place dashboard screenshots here for the README.

## How to capture

1. Open the dashboard in Databricks SQL Dashboard UI
2. For each page (Sales Insights, Marketing Insights), take a full-page screenshot
3. Save as:
   - `sales-insights-dashboard.png`
   - `marketing-insights-dashboard.png`
4. Reference them in the main README.md
